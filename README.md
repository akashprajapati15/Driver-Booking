DriverApp: Real-Time Driver Booking Platform
DriverApp is a professional full-stack MERN application designed to bridge the gap between vehicle owners and professional drivers. Built with a focus on real-time interactivity and seamless user experience, the platform allows users to book professional drivers for their personal vehicles on demand.
Features
User (Vehicle Owner) Dashboard
Real-Time Booking: Request a driver instantly using Socket.io.
Interactive Maps: Pin your pickup location accurately using Leaflet.js and OpenStreetMap.
Vehicle Management: Add and manage multiple vehicles under your profile.
Live Status Updates: Get instant notifications when a driver accepts your ride.
Driver Dashboard
Live Request Alerts: Receive incoming ride requests with a specialized alert system.
Accept/Decline System: View passenger details, location, and vehicle type before accepting.
Interactive Navigation: View the passenger's pinned location on the map for easy navigation.
AI Assistant (Chatbot)
Smart Support: Integrated Hugging Face AI to help users understand how to use the platform, navigate features, and answer general queries.
Security and Authentication
JWT Authentication: Secure login and registration.
Role-Based Access: Specialized interfaces for Users and Drivers to ensure a clean user experience.
